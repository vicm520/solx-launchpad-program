# Security Policy

## Scope

This policy covers the latest SOLX Launchpad program deployed to Solana
Devnet at:

`2AVaQ45R5u1DE4JyvtQ76fUDm72CLSXMRfBQ8d3TPHjA`

The program is a development and learning build. It has not been audited and
must not be treated as production-ready financial software.

## Reporting A Vulnerability

Use this repository's
[private vulnerability reporting form](https://github.com/vicm520/solx-launchpad-program/security/advisories/new).
Include the affected instruction or account, impact, reproduction steps, and
relevant Devnet transaction signatures.

Do not exploit a vulnerability, access other users' accounts, move funds that
you do not own, or publish the issue before a fix is available.

## Bounty

This open-source learning project does not currently offer a bug bounty.
